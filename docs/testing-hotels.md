[Как читать матрицы](README.md#check-catalog). Все разделы сопоставлены статически с требованиями и кодом; статусы не означают успешный прогон.

## Чтение каталога отелей

Источники: FR-03, FR-10 и REST-спецификация. Детальные границы query-параметров дополнительно заданы в [объявлениях Query маршрута](https://github.com/riqkyvf/hotel-booking-api/blob/0d8396f38c8a7b727648585e33b3d34fe54652ab/app/api/v1/hotels.py), формирующих машинный контракт. Общие условия: запрос гостя, если роль не указана; изолированная выборка по уникальному городу, кроме общего списка и рейтинга без города. ## Управление отелями

Источники: FR-03, FR-10 и REST-спецификация. Общие условия: действующий JWT admin, отдельный неархивный отель с одним номером без бронирований; POST создаёт новый отель, PUT/DELETE работают с подготовленным.
